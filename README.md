# AGC Python

FastAPI application with Jinja2 templates. Install dependencies and run:

```bash
pip install -r requirements.txt
python app.py
```

Set API credentials through environment variables before starting the app:

```bash
export DOOD_API_KEY="your-dood-api-key"
export LULU_API_KEY="your-lulu-api-key"
```

On Windows PowerShell, use `$env:DOOD_API_KEY="..."` and
`$env:LULU_API_KEY="..."`.
